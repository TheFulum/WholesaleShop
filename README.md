# WholesaleShop

Интернет-магазин продуктов с розничными и оптовыми ценами: каталог, корзина, заказы с самовывозом и панель администратора с отчётами.

## О проекте

Магазин рассчитан на две группы покупателей. Обычный покупатель оформляет заказ по розничной цене. Покупатель с подтверждённым оптовым статусом получает скидку, которая зависит от количества товара. Администратор управляет каталогом, ценовыми уровнями, пунктами самовывоза и заказами, а также выгружает отчёты в Excel.

Проект — развитие первой версии магазина из репозитория [shop](https://github.com/TheFulum/shop).

## Возможности

**Для покупателя**
- Каталог товаров и подробная карточка: производитель, страна, состав, пищевая ценность (КБЖУ), условия хранения.
- Оценка товаров, средний рейтинг.
- Корзина с изменением количества и автоматическим пересчётом цены по оптовым уровням.
- Оформление заказа с выбором пункта самовывоза, отмена заказа, история заказов.
- Заявка на получение оптового статуса.
- Согласие с политикой конфиденциальности и условиями использования.

**Для администратора**
- Управление товарами, остатками и изображениями.
- Оптовые ценовые уровни: скидка в зависимости от количества.
- Рассмотрение заявок на оптовый статус.
- Управление заказами и их статусами, пунктами самовывоза и пользователями.
- Отчёты по заказам с графиками и экспортом в Excel.
- Редактирование юридических документов прямо с сайта.

## Технологии

- C#, ASP.NET Core 8 MVC, Razor
- Entity Framework Core 8 с миграциями, MySQL
- Cookie-аутентификация, хеширование паролей BCrypt
- ClosedXML для выгрузки в Excel, Chart.js для графиков
- Bootstrap, Bootstrap Icons

## Структура

```
Shop/Controllers/   каталог, корзина, заказы, аккаунт и администрирование
Shop/Models/        товары, заказы, оптовые уровни, заявки, пункты самовывоза, документы
Shop/Helpers/       расчёт оптовой цены
Shop/Migrations/    миграции базы данных
Shop/Views/         страницы магазина и панели администратора
```

## Запуск

Нужны .NET 8 SDK и MySQL. Укажите пароль базы в `Shop/appsettings.json` вместо `YOUR_DB_PASSWORD`, примените миграции командой `dotnet ef database update` и запустите `dotnet run` из папки `Shop`.
